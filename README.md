# Starfish Binding Generator
There are IDL files for web interface classes in src directory,
```sh
$ find src/ -name *.idl
src/extra/History.idl
src/extra/Navigator.idl
src/extra/SourceBuffer.idl
...
```
From those files, binding code could be auto generated by code generator.

# How to use
Start from Starfish root directory.
### Generating code from IDL files in `src` directory
```sh
$ ./binding_generator/scripts/starfish_code_generator.py src/
```
It will generate `src/binding/[IDLFileName].cpp` for each IDL.  
See,
```sh
$ ls -1 src/binding/
AttrBinding.cpp
BlobBinding.cpp
Builtin.idl
CDATASectionBinding.cpp
...
```
### Generating code from a single IDL file
```sh
$ ./binding_generator/scripts/starfish_code_generator.py -f [IDLFile] src/
```
For example,
```sh
$ ./binding_generator/scripts/starfish_code_generator.py -f src/extra/Blob.idl src/
Generated IR from src/extra/Blob.idl
Generated Code for Module "Blob"
```
The result file is `src/binding/BlobBinding.cpp`.

Note that you still have to specify `src/` at the end of the command.
Because an IDL file can have dependancies to others so it needs informations where to find dependant IDLs.  
In Starfish, specifying `src/` at the end works fine.
